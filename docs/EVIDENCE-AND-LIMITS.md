# Public evidence and its limits

This edition supports examination of the research question, the declared comparison rules, the reported outcome categories and their arithmetic. It gives readers enough information to challenge the interpretation of the aggregate counts. It does not provide the materials needed to independently regenerate the experiment.

| Reader question | What this edition supports |
| --- | --- |
| What was the comparison intended to test? | The project brief and methods state the matched development question. |
| Are successes, failures and unscored outcomes all represented? | The result tables preserve the planned denominators for the reported studies. |
| Do the October counts agree across files? | The structured summary can be compared with the tables; each row's categories sum to its planned count. |
| Can the underlying model outcomes be verified independently here? | No. The source records and private evaluator required for that check are withheld. |
| Can the experiment be rerun from this edition? | No. The hidden environment implementation is not distributed. |
| Has the task family been validated on an unseen population? | That claim is not supported by this development snapshot. |

The private research archive retains the original records, fixed source manifests and closure checks. Those preserved records support internal provenance; their existence is not a substitute for public or independent verification. No access to that archive is granted by this edition.

## Confidentiality boundary

The distribution excludes environment equations, equivalent implementations or descriptive reconstructions, hidden configurations, detailed test generation, answer values and action-observation sequences that could reveal the mechanism. Participant programs and discovery notes are also excluded. A mechanism found by a participant still requires protection when its record would disclose the environment.

The public file set is deliberately small: explanatory text, coarse outcome counts and a license. It includes no simulator, executable scoring implementation, raw transcript, hidden-data archive or original Git history. Summaries are reviewed as a set because separately innocuous details can reveal more when combined.

## Interpretation limits

The selected levels were developed using prior observations. Four fixed starting conditions and a single reported session provide an interim calibration signal, not an established difficulty curve. Time effects, stochastic responses and the recorded recovery policy limit interpretation of repeated runs. Technical completion does not establish scientific validity.

An earlier public distribution exposed evaluation internals. Removing them from this edition does not restore an assurance that the family was never disclosed. Prior access and possible copies cannot be ruled out. [Publication history](PUBLICATION-HISTORY.md) records the resulting scope of this revision.
