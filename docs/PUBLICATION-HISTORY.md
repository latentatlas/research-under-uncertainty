# Publication history and revised scope

The portfolio entry originally described a September 2026 pilot with executable replay material and detailed records. A later October distribution included protected evaluation internals. Public access to that repository was closed on 17 October 2026.

This edition, prepared on 18 October 2026, provides a newly written research summary and coarse results. It omits the protected implementations, configurations, participant solutions and reconstructive evidence. Its public verification scope is therefore narrower than that of the earlier executable package.

The first October calibration session is identified separately from the earlier September pilot. The remaining calibration session is outside this snapshot, and a completed validation result is not implied.

## Existing portfolio references

Readers arriving through the project address or the portfolio-v0.1 reference should use this edition's stated scope. This is a revised summary dated 18 October 2026. The original September files and Git objects are not part of this distribution.

This edition does not include the old repository history. Existing deep links to old commits, pull requests and workflow artifacts are outside the compatibility scope. The public summaries do not grant access to the private evidence archive.

## Prior exposure

Restricting access and changing a distribution cannot recall copies already obtained. We therefore do not describe the existing evaluation family as never publicly exposed, nor claim that every possible future participant is free of prior knowledge. Future claims about hidden evaluation require their own disclosure and access assessment.
