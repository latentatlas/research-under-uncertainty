# Limitations and next experiments

This snapshot is an ongoing research prototype and a small work sample. The current evidence supports descriptive distinctions within the recorded pilot.

- **Sampling:** four runs, one model/reasoning profile, two already-known development worlds and one N8 size. No population model ranking or calibrated difficulty curve follows.
- **Causality:** observed revision and later success do not isolate the causal value of an experiment. Time, number of observations and other choices differ between trajectories.
- **Original question:** the wider gap between possessing knowledge and using it in unfamiliar research has not been directly established by independent knowledge tests.
- **Process judgments:** ratings are assistant-authored and outcome-aware. Independent human agreement, blinding and style sensitivity remain unmeasured. The deterministic replay does not resolve those questions.
- **Aggregation:** the conservative D2 rule can hide useful scientific choices when invalid post-closure actions are included. Alternative scope readings remain visible beside the original profile.
- **Tools:** this case demonstrates experiment selection and explanation revision, not invention of a new measurement tool or a saved reusable recipe.
- **Delivery:** two runs ended in submission-protocol errors. Local diagnostics accepted an existing result through the documented submission path, but did not establish the remote cause or repair the live outcomes.
- **Alignment:** ordinary protocol errors and scope requests are not treated as evidence of malicious intent, hacking or general misalignment.
- **Resources:** all 56 participant requests in this pilot have usage records. They used 1,444,895 input and 40,417 output tokens; 248,064 cached input tokens are included in the input total. A separate probe and uninstrumented main-researcher usage must not be silently merged or counted as zero. No FLOP or monetary inference is made.

The immediate scientific next step is a small submission-specific end-to-end probe using a known result that requires no scientific discovery. The earlier arithmetic probe did not exercise delivery. After diagnosing that path, the plan is a matched experiment on response to counterevidence while retaining the same task. Broad generalization and regular or exponential difficulty require separate work. Human-reader consistency remains deferred under the current research plan.

The public replay is intentionally scoped to an inspectable research example. It is a foundation for critique and further validation, not a claim that those future milestones have been completed.
